# PhysioGraphBench v1.2.1 — E3 artifact verifier fix

Release date: 2026-11-06. This release fixes the E3 artifact verifier to check
the shipped tree directly: 192 physical records, comprising 188 effective
records and four retained superseded originals. It adds regression coverage
for missing, unlisted and hash-mismatched records and updates the verification
instructions, version metadata and distribution checksums. Records, results
and all other code are unchanged from v1.2.0.

This release is archived as [10.5281/zenodo.23998329](https://doi.org/10.5281/zenodo.23998329).
